# IMPORTANT: Spotify basic-pitch only supports Python 3.8–3.11.
# On macOS with Python ≥3.12 it tries to pull tensorflow-macos, which has
# no wheels for modern Python — pip will fail. Use a dedicated 3.10/3.11 venv.
#
# Recommended (Apple Silicon / Intel macOS):
#   mise install python@3.11   # or brew install python@3.11
#   python3.11 -m venv .venv-mir
#   .venv-mir/bin/pip install -U pip
#   .venv-mir/bin/pip install -r scripts/mir/requirements.txt
#   # Settings → MIR Python path:  /abs/path/to/.venv-mir/bin/python
#
# Chords-only (any recent Python, no Basic Pitch):
#   pip install -r scripts/mir/requirements-chords.txt
